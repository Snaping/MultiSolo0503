# 前端面经系统 - 技术规格说明

## 1. 项目概述

**项目名称**: 前端面经系统
**项目类型**: 交互式Web应用（单页应用）
**核心功能**: 按技术栈分类汇总前端高频面试知识点，通过图标和动画讲解技术原理
**目标用户**: 前端求职者、面试准备者

## 2. 技术方案

- **前端框架**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **图标库**: Font Awesome 6.x (CDN)
- **动画库**: Animate.css 4.x (CDN)
- **代码高亮**: Prism.js (CDN)
- **数据结构**: JSON 对象存储面试知识点
- **响应式设计**: 移动端优先，支持桌面端

## 3. 目录结构

```
FindJob/
├── index.html          # 主页面
├── styles.css          # 样式文件
├── app.js              # 应用逻辑
└── data.js              # 面试知识点数据
```
