# 多平台评论抓取系统 - 规格文档

## 1. 项目概述

**项目名称**: MultiPlatformCommentSpider
**项目类型**: 桌面应用（Electron + React）
**核心功能**: 抓取抖音、快手、小红书、淘宝等平台的真实评论数据
**目标用户**: 电商运营、数据分析师、内容创作者

## 3. 功能规格

### 3.1 核心功能

**平台支持**:
1. 抖音 (douyin)
   - 视频评论
   - 需要视频ID或分享链接
   - 可抓取: 评论内容、用户信息、点赞数、回复数、发布时间

2. 快手 (kuaishou)
   - 视频评论
   - 需要视频链接或ID
   - 可抓取: 评论内容、用户信息、点赞数、回复数、发布时间

3. 小红书 (xiaohongshu)
   - 笔记评论
   - 需要笔记链接
   - 可抓取: 评论内容、用户信息、点赞数、回复数、发布时间

4. 淘宝 (taobao)
   - 商品评价
   - 需要商品链接
   - 可抓取: 评价内容、用户信息、评分、购买属性、发布时间

5. 自定义URL
   - 支持手动输入任意平台URL
   - 自动识别平台类型

### 3.2 用户交互流程

1. **选择平台**: 点击平台图标，按钮变为选中状态
2. **输入链接**: 在输入框中粘贴视频/商品链接
3. **配置参数**: 设置抓取数量、延迟时间等
4. **开始抓取**: 点击"开始抓取"按钮
5. **实时监控**: 观察进度条和数据列表实时更新
6. **暂停/继续**: 可随时暂停和继续抓取任务
7. **停止任务**: 完全停止抓取任务
8. **导出数据**: 将数据导出为Excel/CSV文件

### 3.3 数据处理流程

**抓取流程**:
```
用户输入URL
    ↓
解析URL获取平台类型和内容ID
    ↓
构建API请求
    ↓
发送请求获取评论数据
    ↓
解析和清洗数据
    ↓
存储到本地状态
    ↓
实时更新UI
    ↓
循环直到达到目标数量或被停止
```

**数据字段**:
- id: 唯一标识符
- platform: 平台名称
- content_id: 原始内容ID
- username: 用户昵称
- user_id: 用户ID
- content: 评论内容
- publish_time: 发布时间
- like_count: 点赞数
- reply_count: 回复数
- rating: 评分(仅淘宝)
- crawl_time: 抓取时间
- is_reply: 是否为回复

### 3.4 边界情况处理

- 无效URL: 提示"请输入有效的链接"
- 网络错误: 显示错误信息，支持重试
- 反爬限制: 自动降低请求频率
- 数据为空: 提示"该内容暂无评论"
- 登录限制: 提示需要登录
- IP封禁: 自动切换代理或提示用户
- 任务中断: 保存已抓取数据
- 大量数据: 分页加载，虚拟滚动

## 4. 技术架构

### 4.1 技术栈

- **前端框架**: Electron + React 18
- **UI库**: Tailwind CSS
- **状态管理**: React Context + useReducer
- **HTTP客户端**: Axios
- **数据表格**: TanStack Table
- **进度展示**: 自定义进度条组件
- **导出功能**: xlsx库
- **IPC通信**: Electron IPC
